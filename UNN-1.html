Pattern

A pattern is something that repeats or gives useful information. A neural network learns patterns in data instead of being given every rule manually.

Maybe you notice ears, eyes, fur, shape and many other features.

A neural network tries to do something similar: find useful patterns in data and use them to make a prediction.

Each tiny decision maker is inspired by a neuron .

Neuron

A neuron receives inputs, processes them, and produces an output. Artificial neurons are mathematical units inspired loosely by biological neurons.

One neuron might respond to one kind of feature. Another might respond to something else.

Together, many neurons can learn complicated patterns.

Chapter 03

Why do we need layers?

A complicated problem becomes easier when it is broken into smaller levels of patterns.

Imagine looking at a photograph.

Pixels
→
Edges
→
Shapes
→
Features
→

These different levels are represented using layers .

Layers

A neural network is organized into layers. The input layer receives data, hidden layers transform the information, and the output layer produces the final prediction.

Early layers can learn simpler patterns. Deeper layers can combine those patterns into more complex representations.

Simple patterns → Complex patterns

This is one reason deeper neural networks can solve complicated problems.

Chapter 04

Not every clue is equally important.

This is where the idea of weights becomes intuitive.

Imagine you are deciding whether an animal is a dog.

🐾 Four legs

Useful clue

Weight: 0.9

🐱 Whiskers

Less useful clue

Weight: 0.2

🐕 Fur

Useful clue

Neural networks assign weights to inputs.

Weight

A weight represents how strongly an input influences a neuron's output. During training, the network adjusts these weights so that its predictions become better.

A large weight means the input has more influence. A smaller weight means it has less influence.

Chapter 05

This is similar to the role of an activation function .

Activation Function

An activation function transforms the neuron's combined input and determines what signal should be passed forward. Common examples include ReLU and sigmoid.

The neuron combines its inputs, applies its weights, and then the activation function helps determine what gets passed to the next layer.

Chapter 06

But how does the network learn?

This is the most important part of the story.

Imagine showing the network this image:

🐱

Correct answer: CAT

But the network says:

🐶 DOG

The network made a mistake. So we need a way to measure how wrong it was.

This difference is called loss .

Loss

Loss is a numerical measure of how far a model's prediction is from the correct answer. During training, the goal is generally to reduce this loss.

📚 Give data
🤖 Predict
❌ Measure error
🔧 Adjust weights
🔁 Try again
Chapter 07

The network learns from its mistakes.

Let's turn this into a small classroom game.

Suppose the correct answer is: CAT

What should the network change?

🤖 Prediction: DOG
The network is still learning...

The process of sending information about the error backward through the network is called backpropagation .

Backpropagation

Backpropagation calculates how the error relates to the network's parameters and provides the information needed to update the weights. This helps the network improve its future predictions.

In simple terms: “You made a mistake. Let's figure out which connections contributed to it and adjust them.”

The network repeats this process over many examples. Each pass through the training data is called an epoch .

Epoch

An epoch means one complete pass through the training dataset. Neural networks often train for many epochs, gradually adjusting their parameters.

Practice → Mistake → Correction → Improvement

That's the basic intuition behind neural network training.

Chapter 09

But AI can still get things wrong.

A neural network learns from the data it receives.

Imagine teaching a student using only 10 pictures of cats.

What happens when you show the student a cat that looks very different?

They might struggle.

📉

Poor Data

If the training data is poor, the model can learn poor patterns.

⚖️

Bias

If the training data contains bias, the model may learn and reproduce it.

🧠

Overfitting

A model can memorize training examples instead of learning patterns that generalize well.

Garbage in → Garbage out

A model cannot magically turn bad or insufficient data into perfect knowledge.
